# inner-sense.org.uk

Temporary landing page and Cloudflare Worker for Inner Sense Therapy.

## Local development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

## Project structure

- `public/` - static assets (HTML, CSS, images)
- `src/index.js` - Worker entry point
- `wrangler.jsonc` - Wrangler configuration
